# B2 Wortschatz und Strukturen:

Thema "Erwartungen von Frauen an Männer"

## Nomen 名詞

- **die Arbeitsteilung** *(f., -en)*  
  → 工作/角色分工  
  → 複合詞詞源：*Arbeit* + *Teilung*（分配）  
  → 例句：Traditionelle Arbeitsteilung zwischen Mann und Frau wird zunehmend infrage gestellt.

- **die Unterstützung** *(f., -en)*  
  → 支持、協助  
  → 來自動詞 *unterstützen*  
  → 例句：Frauen erwarten emotionale und praktische Unterstützung.

- **die Entscheidungsfreiheit** *(f., kein Pl.)*  
  → 決定的自由  
  → 複合詞：*Entscheidung* + *Freiheit*  
  → 例句：Individuelle Entscheidungsfreiheit sollte in jeder Beziehung respektiert werden.

- **die Gleichberechtigung** *(f., kein Pl.)*  
  → 平等權利、兩性平權  
  → 複合詞詞源：*gleich* + *Berechtigung*  
  → 例句：Viele Frauen kämpfen für gesellschaftliche Gleichberechtigung.

- **das Rollenbild** *(n., -er)*  
  → 性別角色形象  
  → 複合詞：*Rolle* + *Bild*  
  → 例句：Traditionelle Rollenbilder sind für viele Frauen nicht mehr akzeptabel.

- **der Respekt** *(m., kein Pl.)*  
  → 尊重  
  → 例句：Respekt ist die Grundlage jeder gleichwertigen Partnerschaft.

- **die Empathie** *(f., kein Pl.)*  
  → 同理心  
  → 例句：Empathie in der Kommunikation ist eine zentrale Erwartung.

- **die Anerkennung** *(f., -en)*  
  → 認可、肯定  
  → 來自 *anerkennen*  
  → 例句：Viele Frauen wünschen sich Anerkennung für ihre Leistungen.

- **die Verantwortung** *(f., -en)*  
  → 責任  
  → 常見搭配：*Verantwortung übernehmen / tragen / teilen*  
  → 例句：Männer sollten Verantwortung in Beziehungen übernehmen.

- **das Patriarchat** *(n., -e)*  
  → 父權制社會  
  → 例句：Das Patriarchat wird von modernen Frauen zunehmend kritisch hinterfragt.

---

## Verben 動詞

- **erwarten (+ Akk. / Nebensatz)**  
  → 期待  
  → 例句：Frauen erwarten, dass Männer sie als gleichwertig behandeln.

- **respektieren (+ Akk.)**  
  → 尊重  
  → 例句：Man sollte die Entscheidung jeder Person respektieren.

- **unterstützen (+ Akk.)**  
  → 支持、協助  
  → 例句：Männer sollen ihre Partnerinnen emotional unterstützen.

- **übernehmen (+ Akk.)**  
  → 承擔（責任、任務）  
  → 例句：Viele Männer sind bereit, mehr familiäre Aufgaben zu übernehmen.

- **anerkennen (+ Akk.)**  
  → 承認、認可  
  → 例句：Die Leistungen der Frauen sollten anerkannt werden.

- **kommunizieren (mit + D)**  
  → 溝通  
  → 例句：Man sollte mit Empathie und Offenheit kommunizieren.

- **reflektieren (+ Akk.)**  
  → 反思  
  → 例句：Moderne Männer reflektieren ihre sozialen Privilegien.

- **hinterfragen (+ Akk.)**  
  → 質疑  
  → 例句：Traditionelle Rollenbilder müssen kritisch hinterfragt werden.

- **zeigen (+ D + Akk.)**  
  → 展示  
  → 例句：Männer können durch ihr Verhalten Respekt zeigen.

---

## Adjektive 形容詞

- **gleichwertig**  
  → 平等價值的  
  → 詞源：*gleich* + *wert*  
  → 例句：Eine gleichwertige Partnerschaft basiert auf gegenseitigem Respekt.

- **emotional**  
  → 情感上的  
  → 例句：Emotionale Unterstützung ist genauso wichtig wie finanzielle.

- **verbindlich**  
  → 有承諾性的、具有約束力的  
  → 例句：Frauen erwarten verbindliche Zusagen in Beziehungen.

- **bereit (zu + Infinitiv)**  
  → 願意（做某事）  
  → 例句：Er ist bereit, Verantwortung zu übernehmen.

- **autonom**  
  → 自主的、自我主導的  
  → 例句：Körperliche Autonomie der Frau muss respektiert werden.

- **traditionell**  
  → 傳統的  
  → 例句：Traditionelle Vorstellungen von Männlichkeit werden oft hinterfragt.

---

## Redemittel & feste Wendungen 語塊與固定搭配

- **Verantwortung übernehmen / tragen**  
  → 承擔責任  
  → *In einer Partnerschaft sollte man gemeinsam Verantwortung übernehmen.*

- **Respekt zeigen / entgegenbringen**  
  → 表現出尊重  
  → *Man soll seinem Gegenüber Respekt entgegenbringen.*

- **sich mit etwas auseinandersetzen**  
  → 深入探討、正視（議題）  
  → *Viele Männer setzen sich mit Gleichstellungsfragen auseinander.*

- **sich gleichberechtigt fühlen**  
  → 感受到平等  
  → *Frauen wollen sich in der Beziehung gleichberechtigt fühlen.*

- **Anerkennung erhalten / bekommen**  
  → 得到認可  
  → *Berufliche Leistungen von Frauen sollten mehr Anerkennung bekommen.*

- **traditionelle Rollenbilder hinterfragen**  
  → 質疑傳統性別角色觀念  
  → *Junge Männer hinterfragen heute häufiger traditionelle Rollenbilder.*
