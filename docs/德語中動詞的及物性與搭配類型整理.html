1132 德文四

第 1 章 德語中動詞的及物性與搭配類型整理

1.1 transitive Verben

及物動詞：能直接接賓語，常見搭配：

1.1.1 1. 只接第四格（+ Akk.）

  • 表示「及物」的最基本結構。
  • 範例：
    • Ich sehe den Mann.
    • Wir essen einen Apfel.

1.1.2 2. 接第三格（人）+ 第四格（物）【+ D + A】

  • 常見於雙賓語結構中，表達「某人給某物、送某物」等概念。
  • 範例：
    • Ich gebe dir ein Buch.
    • Sie zeigt dem Lehrer ihren Aufsatz.

1.1.3 3. 雙第四格（+ Akk. + Akk.）【特殊】

  • 德語中特殊少數動詞同時接兩個第四格賓語，違反常規格位規則
  • 常見動詞：
    • lehren（教導某人某事）
      • Sie lehrt ihn Deutsch.
    • kosten（花費某人某物）
      • Das kostet mich viel Zeit.
    • nennen（稱呼某人為某事）
      • Man nennt ihn einen Lügner.
    • schimpfen（罵某人為某事）
      • Sie schimpft ihn einen Idioten.

1.2 intransitive Verben

不及物動詞：不能接直接賓語，而是搭配其他結構：

1.2.1 1. + Adjektiv（形容詞補語）

  • 常見動詞：sein, werden, bleiben, wirken 等連綴動詞
  • 範例：
    • Ich bin müde.
    • Sie wird alt.
    • Er wirkt nervös.

1.2.2 2. + Nomen（主語補語）【主語 = 名詞】

  • 常見於身份變化、主語說明
  • 範例：
    • Ich werde Lehrer.
    • Er ist mein Freund.

1.2.3 3. + Genitiv（二格賓語）【罕見】

  • 二格支配動詞在現代德語中不常用，需特記。
  • 常見例子：
    • gedenken + Gen.（紀念）
      • Wir gedenken des Opfers.
    • sich bedienen + Gen.（使用某物）
    • bedürfen + Gen.（需要某物）

1.2.4 4. + Dativ（第三格）【注意：不是賓語！】

  • 某些不及物動詞接 第三格對象，但這不代表是及物用法！
  • 代表動詞：helfen, danken, gefallen, gehören
  • 範例：
    • Er hilft dem Mann.
    • Das gehört mir.
  • ✔️ 這些不是及物動詞，不能直接說 “加了對象 = 及物”！

1.2.5 5. + Präposition（介詞結構）

  • 搭配特定介詞形成語義完整的結構
  • 可見於及物或不及物動詞中

1.2.5.1 範例（及物動詞 + 介詞）：

  • verbinden + Akk. mit + Dat.
    • Er verbindet das Kabel mit dem Computer.
  • umstellen + Akk. auf + Akk.
    • Wir stellen die Produktion auf Bio um.

1.2.5.2 範例（不及物動詞 + 介詞）：

  • helfen + Dat. bei + Dat.
    • Sie hilft dem Kind bei den Hausaufgaben.
  • antworten + Dat. auf + Akk.
    • Ich antworte dir auf deine Frage.

1.3 學習建議

在記單詞時，切忌只背動詞原形，一定要同時記住其 格位要求與介詞搭配。這對於中高階學習者尤其重要，直接關係到聽說寫的正確性與語感建立。
