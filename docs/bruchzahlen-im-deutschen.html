第 1 章 Bruchzahlen im Deutschen

德語中的「分數」表達法

1.1 1. 基本構造：幾分之幾的表達

德語中「幾分之幾」＝ Zähler（分子） + Bruch (分母的序數形式 + “-tel”)

  • 分子：用基數詞（Kardinalzahl）表示
  • 分母：用序數詞（Ordinalzahl）+ “-tel” 或 “-stel” 構成

1.1.1 範例：

  • 1/2 → ein Halb(e)
  • 1/3 → ein Drittel
  • 2/3 → zwei Drittel
  • 3/4 → drei Viertel
  • 1/10 → ein Zehntel
  • 5/100 → fünf Hundertstel

1.1.2 注意：

  • 從 “Drittel” 起使用 -tel / -stel 結尾，沒有變格變化。
  • 分數名詞在句中通常作為 中性名詞 (das) 使用：
    • z. B. das Drittel, das Viertel, das Hundertstel
  • 「一半」特別用法：可以用 die Hälfte（陰性名詞）

1.2 2. 常見分數對照表

數字 德語寫法 備註
1/2 ein Halb(e) / die Hälfte 用法特殊，見下節
1/3 ein Drittel 常見中性名詞
1/4 ein Viertel
2/3 zwei Drittel
3/4 drei Viertel
1/10 ein Zehntel
1/100 ein Hundertstel 可延伸為百分率

1.3 3. 特殊表達：一半 ≠ ein Halb

用法 德文 說明
一半的 + 名詞 die Hälfte von + D 作為名詞使用，陰性
數量為一半 ein halbes + N 作為形容詞修飾名詞（中性變化）
表語/主語 ein Halb(e) 作為主語或表語使用，少見

1.3.1 例句：

  • Ich habe die Hälfte des Kuchens gegessen.
    我吃了一半的蛋糕。

  • Er trank ein halbes Glas Wasser.
    他喝了半杯水。

1.4 4. 常見語法結構與句型

1.4.1 表達總數中的一部分：

1.4.1.1 結構 1：[分數] + von + Dativ

  • 最常見、最口語化的表達方式
  • 適用於人、物、抽象名詞，句子通順自然
  • 特別適合 B1–B2 程度書寫與口語使用

範例：

  • Ein Drittel von den Schülern ist krank.
  • Zwei Drittel von der Bevölkerung sind betroffen.
  • Ein Viertel von meinem Gehalt geht für die Miete drauf.

1.4.1.2 結構 2：[分數] + Genitiv

  • 書面語較常見，更精煉正式
  • 用於較正式文章、報導、學術性句子
  • 常與名詞單數或明確可指涉的總體搭配

範例：

  • Ein Drittel der Schüler ist krank.
  • Zwei Drittel der Bevölkerung sind unzufrieden.
  • Ein Viertel des Kuchens wurde gegessen.
  • Drei Viertel des Haushaltsbudgets werden für Lebensmittel verwendet.

1.4.1.3 📝 兩種結構比較：

結構 特點 使用場合
[Bruch] + von + Dativ 通俗、常見於口語 口語表達、輕鬆書信
[Bruch] + Genitiv 書面正式、簡潔清楚 報告、新聞、正式文體

1.4.1.4 注意動詞一致性（主語為分數時）

  • 若分數後的總體名詞為單數 → 動詞通常用單數
    • Ein Drittel des Kuchens ist weg.
  • 若為複數 → 動詞通常用複數
    • Drei Viertel der Schüler sind anwesend.
  • 若強調數學比例本身 → 視為中性名詞（das Drittel 等）→ 單數動詞
    • Ein Drittel ist mehr als ein Viertel.

1.4.1.5 小結句型模板：

  • [Bruchzahl] + von + Dativ → Alltagssprache
  • [Bruchzahl] + Genitiv → Schriftsprache
  • [Bruchzahl] 做主語時，動詞根據語意（單/複數）一致變化

1.4.2 做主語時，動詞依主語（單複數）變化：

  • Ein Drittel ist krank. （單數 → 動詞單數）
  • Drei Viertel sind zufrieden. （複數 → 動詞複數）

1.4.3 結合其他數字使用：

  • 1 ¾ Stunden → eine dreiviertel Stunde（約等於 45 分鐘）
  • 1 ½ Liter → eineinhalb Liter

1.5 5. 拓展用法與短語

1.5.1 常見固定搭配：

德文表達 中文意思
ein Drittel von etwas 某物的三分之一
zwei Drittel der Bevölkerung 人口的三分之二
die Hälfte des Tages 一天的一半
ein Viertel Liter Milch 四分之一公升牛奶

1.6 6. 造句練習

  1. Ein Drittel der Klasse hat die Prüfung bestanden.
    　三分之一的班上同學通過了考試。

  2. Ich habe nur ein Viertel meines Gehalts gespart.
    　我只存下了我薪水的四分之一。

  3. Drei Viertel der Befragten waren mit der Politik unzufrieden.
    　四分之三的受訪者對政策感到不滿。

  4. Wir brauchen noch ein halbes Kilo Mehl.
    　我們還需要半公斤麵粉。

  5. Die Hälfte des Teams ist krankgemeldet.
    　隊伍中有一半的人請病假了。

1.7 7. 小結

  • 分子用基數詞，分母用序數詞加 -tel / -stel
  • 做主語時視為單數或複數取決於語意
  • die Hälfte 是唯一陰性名詞表「一半」的常見形式
  • 可搭配 von + Dativ 表示某物的一部分
