1132 德文四

第 10 章 KB 60-61 重點生詞與短語語境搭配

10.1 Abschnitt 1 – Armut weltweit

10.1.1 名詞 Nomen

  • die Armut (f.)
    → 貧窮、貧困；不可數名詞
    → 語境：soziale Armut, extreme Armut
    → 例句：Extreme Armut betrifft mehr als eine Milliarde Menschen weltweit.
    → 形容詞化：arm (Adj.)

  • die Grundlage (f., -n)
    → 基礎、根據
    → 複合詞詞源：Grund（根本）+ Lage（狀況）
    → 常見語塊：auf der Grundlage von …
    → 例句：Auf der Grundlage internationaler Kriterien lässt sich Armut vergleichen.

  • die Auswirkung (f., -en)
    → 影響、後果（通常為負面）
    → 詞源：wirken（產生作用）+ aus-（出）
    → 介詞搭配：eine Auswirkung auf + Akk.
    → 例句：Armut hat starke Auswirkungen auf die Gesundheit.

  • die Naturkatastrophe (f., -n)
    → 天然災害
    → 複合詞：Natur（自然）+ Katastrophe（災難）
    → 例句：Naturkatastrophen können ganze Ernten vernichten.

  • das Bevölkerungswachstum (n.)
    → 人口成長
    → 複合詞：Bevölkerung（人口）+ Wachstum（成長）
    → 例句：Ein starkes Bevölkerungswachstum erschwert die Armutsbekämpfung.

  • die Krankheit (f., -en)
    → 疾病
    → 搭配：an einer Krankheit leiden, gegen eine Krankheit kämpfen
    → 例句：Viele arme Menschen haben keinen Zugang zu medizinischer Hilfe bei Krankheiten.

10.1.2 動詞 Verben

  • etwas erfassen (Verb, + Akk.)
    → 掌握、記錄、理解
    → 拆解詞源：er-（強調）+ fassen（抓住）
    → 語境搭配：Daten erfassen, Informationen erfassen, Armut erfassen
    → 例句：Die Kriterien helfen dabei, Armut besser zu erfassen.

  • etwas untersuchen (Verb, + Akk.)
    → 調查、研究、檢查
    → 搭配語境：eine Situation / ein Problem untersuchen
    → 例句：Die Weltbank untersuchte, wie Arme ihre Lage selbst einschätzen.

  • sich einschätzen (Verb, + Akk. reflexiv)
    → 自我評估
    → 常搭配副詞：realistisch, positiv, negativ
    → 例句：Die Armen schätzen sich selbst oft als chancenlos ein.

  • ausgeliefert sein (Verb, + Dativ + Adj.)
    → 無力反抗，被動處於⋯⋯之下（被支配、無保護）
    → 常搭配：etwas/jemandem schutzlos ausgeliefert sein
    → 例句：Viele Menschen sind Naturkatastrophen schutzlos ausgeliefert.

  • etwas bestimmen (Verb, + Akk.)
    → 決定、主導、界定
    → 搭配語境：über das eigene Leben bestimmen
    → 例句：In Armut lebende Menschen können oft nicht selbst über ihr Leben bestimmen.

10.1.3 形容詞 & 固定語塊

  • anerkannt (Partizip II von anerkennen)
    → 被承認的，受公認的
    → 拆解詞源：an- + erkennen（認識）
    → 例句：Es gibt international anerkannte Kriterien zur Messung von Armut.

  • nötig (Adj., 原形)
    → 必要的，必需的
    → 常搭配語塊：die nötigsten Dinge des Alltags
    → 例句：Oft fehlt das Geld für die nötigsten Dinge.

  • schutzlos (Adj., 原形)
    → 無保護的，暴露無遺的
    → 拆解：Schutz（保護）+ -los（無⋯⋯的）
    → 例句：Arme Menschen sind Gewalt oft schutzlos ausgeliefert.

  • ausgeliefert (Adj. / Partizip II von ausliefern)
    → 被交出、交付、任人擺布的
    → 常與 schutzlos 連用
    → 例句：Sie waren der Gewalt ausgeliefert.

10.1.4 語塊 / Redemittel

  • als arm gelten
    → 被視為貧窮者
    → 例句：Wer weniger als 1,90 Dollar am Tag verdient, gilt als extrem arm.

  • keine Aussicht auf eine bessere Zukunft
    → 沒有對更好未來的希望
    → 例句：Viele Arme sehen keine Aussicht auf eine bessere Zukunft.

  • Hunger, kein Geld, keine Sicherheit
    → 高頻描述貧窮狀態的三重結構（常出現於報導、演講中）

10.2 Abschnitt 2 – Armut und Gesundheit

10.2.1 名詞 Nomen

  • die Ausgrenzung (f., -en)
    → 排除、隔離（特指社會層面）
    → 動詞來源：ausgrenzen（排除）
    → 語境：soziale Ausgrenzung, kulturelle Ausgrenzung
    → 例句：Armut führt oft zu sozialer Ausgrenzung.

  • die Gesundheit (f.)
    → 健康狀態（不可數）
    → 常與 fördern / schützen / gefährden 搭配
    → 例句：Armut kann die Gesundheit langfristig gefährden.

  • die Lebenslage (f., -n)
    → 生活處境、人生情境
    → 複合詞詞源：Leben + Lage（情況）
    → 語境：in schwierigen Lebenslagen
    → 例句：Der Kongress beschäftigt sich mit Menschen in schwierigen Lebenslagen.

  • der Vortrag (m., ⸚e)
    → 演講、報告
    → 拆解詞源：vor-（前）+ tragen（帶來）
    → 例句：Frau Prof. Meyer hält einen Vortrag zum Thema Armut.

  • der Kongress (m., -e)
    → 會議、學術大會
    → 語境：medizinischer / politischer Kongress
    → 例句：Der Public Health-Kongress findet an der TU Berlin statt.

  • der Frühbucherrabatt (m., -e)
    → 早鳥優惠
    → 複合詞：früh（早）+ Bucher（預訂者）+ Rabatt（折扣）
    → 例句：Bis zum 5. Januar gibt es Kongresskarten zum Frühbucherrabatt.

10.2.2 動詞 Verben

  • etwas fördern (Verb, + Akk.)
    → 促進、推動（抽象事物如健康、教育、平等）
    → 例句：Der Kongress soll die Gesundheit langfristig fördern.

  • sich anmelden (für + Akk.) (Verb: anmelden)
    → 報名參加
    → 常搭配：sich für eine Veranstaltung anmelden
    → 例句：Man kann sich ab sofort für den Kongress anmelden.

  • stattfinden (Verb: stattfinden)
    → 舉行、發生（事件性活動）
    → 不可分動詞，常與 Zeit/Ort 搭配
    → 例句：Der Kongress findet am 13. und 14. März in Berlin statt.

  • etwas thematisieren (Verb, + Akk.)
    → 討論（作為主題），使⋯成為主題
    → 例句：In Seminaren werden Strategien zur Gesundheitsförderung thematisiert.

10.2.3 形容詞 & 固定表達

  • langfristig (Adj.)
    → 長期的（與 kurzfristig 相對）
    → 拆解詞源：lang + Frist（期限）
    → 例句：Es geht darum, die Gesundheit langfristig zu fördern.

  • wesentlich (Adj.)
    → 本質的、重要的
    → 詞源：Wesen（本質）+ -lich
    → 例句：Armut ist ein wesentlicher Faktor für viele Gesundheitsprobleme.

10.2.4 語塊 / Redemittel

  • Armut macht krank – Krankheit macht arm?!
    → 雙向因果句，典型社會學論點句式
    → 可用於作文：Es lässt sich fragen, ob Armut krank macht oder Krankheit zu Armut führt.

  • Strategien zur Verbesserung der Gesundheitschancen
    → 固定搭配語塊，常見於政府／NGO文件

  • Menschen in schwierigen Lebenslagen
    → 表脆弱族群的正式說法（替代「arme Menschen」）

  • sich für etwas anmelden
    → 報名某活動；可轉換成被動句：Die Anmeldung für den Kongress ist ab sofort möglich.

10.3 Abschnitt 3 – Soziale Hilfe & Kleiderausgabe

10.3.1 名詞 Nomen

  • die Kleiderausgabe (f., -n)
    → 衣物發放處
    → 複合詞：Kleider（衣物）+ Ausgabe（發送、分發）
    → 例句：Der DRK-Ortsverein hat eine Kleiderausgabe eröffnet.

  • die Spende (f., -n)
    → 捐贈、捐助
    → 常搭配：eine Spende abgeben / erhalten / sammeln
    → 例句：Vielen Dank für Ihre Spendenbereitschaft.

  • der Hausrat (m.)
    → 家庭用品、生活物資（集合名詞）
    → 複合詞：Haus + Rat（舊意：財產、裝備）
    → 例句：Viele Bedürftige nehmen auch Hausrat wie Geschirr oder Decken mit.

  • die Notlage (f., -n)
    → 緊急困境、急難處境
    → 複合詞：Not（危難）+ Lage（情況）
    → 例句：Auch Menschen in akuten Notlagen erhalten Hilfe.

  • der Bedürftige / die Bedürftigen (m./pl.)
    → 貧困者、有需要者（形容詞名詞化）
    → 例句：Die Kleidung wird an Bedürftige gegen eine geringe Gebühr abgegeben.

  • die Kleiderspendenbox (f.)
    → 衣物捐贈箱
    → 複合詞：Kleider + Spende + Box
    → 例句：Bitte werfen Sie Ihre Spende nur in die Kleiderspendenbox ein.

10.3.2 動詞 Verben

  • etwas eröffnen (Verb, + Akk.)
    → 開設、啟用（如商店、服務）
    → 搭配：eine Filiale / eine Kleiderausgabe eröffnen
    → 例句：Das DRK hat eine neue Kleiderausgabe eröffnet.

  • etwas abgeben (Verb, + Akk.)
    → 交出、捐出
    → 常見結構：eine Spende / Kleidung abgeben
    → 例句：Sie können Ihre Spende zu den Öffnungszeiten abgeben.

  • etwas einsortieren / aufbereiten (Verb, + Akk.)
    → 整理 / 整理再利用（如舊衣物）
    → 例句：Die Kleidung wird gereinigt und aufbereitet.

  • jemandem zur Verfügung stehen (Verbkonstruktion, Dativ)
    → 可供⋯使用（固定語塊）
    → 例句：Die Spenden stehen den Bedürftigen zur Verfügung.

10.3.3 形容詞 & 固定表達

  • bedürftig (Adj., von „Bedürfnis“)
    → 有需求的、貧困的
    → 例句：Die Ausgabe richtet sich an bedürftige Menschen.

  • gut erhalten (Partizipialkonstruktion)
    → 保存良好的（常修飾物品）
    → 例句：Bitte nur gut erhaltene Kleidungsstücke einwerfen.

  • akut (Adj.)
    → 急性的、突發的（可用於醫療 / 社會困境）
    → 例句：Auch Menschen in akuten Notlagen erhalten Unterstützung.

  • sozial (Adj.)
    → 社會的；社會公益的
    → 用法：soziale Arbeit / soziale Einrichtung

10.3.4 語塊 / Redemittel

  • soziale Arbeit leisten
    → 從事社會服務
    → 例句：Viele Menschen engagieren sich ehrenamtlich und leisten soziale Arbeit.

  • eine geringe Gebühr (von … Euro)
    → 少量費用
    → 例句：Die Kleidung kostet nur eine geringe Gebühr von 0,50–2 €.

  • etwas zur Verfügung stellen
    → 提供某物供他人使用
    → 例句：Das DRK stellt Kleidung zur Verfügung.

  • gegen eine Gebühr abgeben
    → 以象徵性費用提供
    → 例句：Die Kleidung wird gegen eine geringe Gebühr abgegeben.

10.4 Abschnitt 4 – Soziale Herkunft & Bildung

10.4.1 名詞 Nomen

  • die soziale Herkunft (f.)
    → 社會出身、家庭背景
    → 拆解：sozial（社會的）+ Herkunft（來源）
    → 例句：Zwischen sozialer Herkunft und Bildungschancen besteht ein Zusammenhang.

  • die Bildungschance (f., -n)
    → 教育機會
    → 複合詞：Bildung + Chance
    → 例句：Kinder aus armen Familien haben oft schlechtere Bildungschancen.

  • die Fördermaßnahme (f., -n)
    → 支援措施、補助教學活動
    → 複合詞：fördern + Maßnahme（措施）
    → 例句：Die Familie kann sich Fördermaßnahmen wie Musikunterricht leisten.

  • die Nachhilfestunde (f., -n)
    → 補習課、課後輔導
    → 複合詞：Nachhilfe（補助）+ Stunde（課）
    → 例句：Eltern zahlen oft problemlos für Nachhilfestunden.

  • der Bildungsabschluss (m., ⸚e)
    → 學歷、教育程度
    → 複合詞：Bildung + Abschluss（結業）
    → 例句：Eltern mit hohem Bildungsabschluss legen Wert auf Bildung.

  • die Leistungsbereitschaft (f., -en)
    → 學習動力、願意付出努力
    → 複合詞：Leistung（表現）+ Bereitschaft（意願）
    → 例句：Gute Vorbilder stärken die Leistungsbereitschaft der Kinder.

10.4.2 動詞 Verben

  • aufwachsen (Verb, ohne Präp.)
    → 成長於⋯（不及物動詞）
    → 常與地點 / 家庭狀況搭配：in einer sicheren Familie aufwachsen
    → 例句：Kinder, die ökonomisch sicher aufwachsen, haben mehr Chancen.

  • sich leisten können (+ Akk.)
    → 有能力負擔（錢 / 時間）
    → 搭配：sich Musikunterricht / Kurse leisten können
    → 例句：Die Familie kann sich Sportkurse problemlos leisten.

  • abhängen von + Dativ (Verb: abhängen)
    → 取決於⋯⋯
    → 結構：X hängt von Y ab
    → 例句：Der Bildungserfolg hängt stark von der Herkunft ab.

  • etwas ermöglichen (+ Dativ / Akk.)
    → 使有可能、促成
    → 常見搭配：eine gute Bildung / ein Studium ermöglichen
    → 例句：Die Eltern möchten ihren Kindern gute Bildung ermöglichen.

  • etwas vorleben (+ Dativ)
    → 以身作則、示範行為
    → 結構：jemandem etwas vorleben
    → 例句：Die Eltern leben ihren Kindern vor, dass Bildung wichtig ist.

  • etwas erachten als + Akk. (formell)
    → 視為⋯⋯
    → 結構：etwas als wichtig / notwendig erachten
    → 例句：Sie erachten Bildung als besonders wichtig.

10.4.3 形容詞 & Partizipien

  • ökonomisch (Adj.)
    → 經濟上的
    → 常見語境：ökonomisch sicher / benachteiligt
    → 例句：Ein Kind aus ökonomisch sicherem Elternhaus hat bessere Chancen.

  • erfolgreich (Adj.)
    → 成功的；詞源：Erfolg + -reich
    → 例句：Eltern, die beruflich erfolgreich sind, legen Wert auf Bildung.

  • erstrebenswert (Adj.)
    → 值得追求的
    → 拆解：erstreben（渴望）+ -wert（有價值的）
    → 例句：Den Kindern wird vermittelt, dass Bildung erstrebenswert ist.

10.4.4 語塊 / Redemittel

  • „Der Apfel fällt nicht weit vom Stamm.“
    → 常用德語俗語，比喻子女多承襲父母背景
    → 可延伸為：Soziale Herkunft beeinflusst die Entwicklung der Kinder.

  • mehr Geld = besser in der Schule?
    → 典型因果反諷句，適合作文導入對比觀點

  • sich positiv / negativ auf … auswirken
    → 對⋯⋯產生正 / 負面影響（B2論說核心句型）

  • Bildung wird im Alltag und in der Freizeit geschätzt.
    → 書面表達：eine hohe Wertschätzung für Bildung zeigen
