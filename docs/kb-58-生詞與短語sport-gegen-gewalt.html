第 3 章 KB 58 生詞與短語：Sport gegen Gewalt

3.1 Abschnitt 1 – Soziale Probleme in Hamburg

3.1.1 Nomen

  • die Großstadt (f., ⸚e)
    → 大城市
    → 例句：Wie in jeder Großstadt gibt es auch in Hamburg soziale Probleme.

  • der Stadtteil (m., -e)
    → 城市區域、社區
    → 複合詞：Stadt + Teil
    → 例句：Ein sozial schwacher Stadtteil ist oft von Armut betroffen.

  • das Einkaufszentrum (n., -zentren)
    → 購物中心
    → 複合詞：Einkauf + Zentrum
    → 例句：Die Jugendlichen hielten sich oft im Einkaufszentrum auf.

  • die Langeweile (f., kein Pl.)
    → 無聊
    → 常與動詞 sich vertreiben / haben / empfinden 搭配
    → 例句：Man vertreibt sich seine Langeweile mit Kleinigkeiten.

  • der Diebstahl (m., ⸚e)
    → 偷竊行為
    → 拆解：stehlen（偷）+ -stah(l)（名詞化）
    → 例句：Kleine Diebstähle wurden zum Alltag.

3.1.2 Verben

  • vertreiben (+ sich + Dat. / Akk.)
    → 驅散、打發（時間、無聊）
    → 例句：Die Jugendlichen vertrieben sich die Zeit mit Unsinn.

  • klauen (+ Akk.)
    → 偷竊（口語）
    → 同義詞：stehlen（書面語）
    → 例句：Einige Jugendliche klauen aus Langeweile.

  • sprühen (+ Akk.)
    → 噴灑、塗鴉
    → 搭配：Graffiti sprühen
    → 例句：An die Wände wurden Graffiti gesprüht.

  • stehlen (+ Akk., stiehlt – stahl – gestohlen)
    → 偷竊（正式）
    → 例句：Die Jugendlichen stehlen manchmal Handtaschen.

3.1.3 Adjektive

  • sozial schwach (Adj.-Phrase)
    → 社會弱勢的（常形容社區、家庭）
    → 例句：Ein sozial schwacher Stadtteil braucht Unterstützung.

  • warm und trocken (Adj.-Phrase)
    → 溫暖又乾燥（形容避風港的環境）
    → 例句：Im Einkaufszentrum war es warm und trocken.

3.2 Abschnitt 2 – Fahim Yusufzai als Sicherheitsleiter

3.2.1 Nomen

  • der Sicherheitsleiter (m., -)
    → 安全主管
    → 複合詞：Sicherheit + Leiter
    → 例句：Fahim Yusufzai arbeitete als Sicherheitsleiter.

  • der Afghane (m., -n)
    → 阿富汗人（男性）
    → 語境：ein gebürtiger Afghane = 阿富汗出生者

  • das Hausverbot (n., -e)
    → 禁入令
    → 複合詞：Haus + Verbot
    → 例句：Wer erwischt wurde, bekam ein Hausverbot.

  • das Führungszeugnis (n., -se)
    → 品行證明（常作為求職文件）
    → 複合詞：Führung（行為）+ Zeugnis（證明）

  • die Polizei (f., -en)
    → 警方
    → 例句：Er übergab die Jugendlichen der Polizei.

3.2.2 Verben

  • arbeiten als + Nomen (Verb: arbeiten)
    → 擔任⋯⋯職位
    → 例句：Er arbeitete viele Jahre als Sicherheitsleiter.

  • jemanden schnappen (+ Akk.)
    → 抓到（某人）做壞事（口語）
    → 例句：Er schnappte Jugendliche beim Klauen.

  • jemanden übergeben (+ Dativ + Akk.)
    → 移交某人給某機關（如警方）
    → 例句：Er übergab die Täter der Polizei.

  • jemandem begegnen (+ Dativ)
    → 偶遇某人
    → 例句：Am nächsten Tag begegnete er ihnen wieder.

  • randalieren (Verb, intransitiv)
    → 鬧事、製造騷亂
    → 例句：Die Jugendlichen randalierten im Einkaufszentrum.

3.2.3 Adjektive

  • gebürtig (Adj.)
    → 出生於⋯⋯的
    → 常見搭配：ein gebürtiger Afghane / Berliner

  • erneut (Adj./Adv.)
    → 再次、重新
    → 例句：Am nächsten Tag traf er sie erneut.

3.2.4 Redemittel / Phrase

  • Hausverbot bekommen
    → 被禁止進入某地
    → 例句：Wer randaliert, bekommt Hausverbot.

  • jemanden der Polizei übergeben
    → 將某人交給警方
    → 例句：Er übergab den Jugendlichen der Polizei.

  • dem Täter erneut begegnen
    → 再次遇見同一嫌疑人
    → 例句：Er begegnete ihm am nächsten Tag erneut.

3.3 Abschnitt 3 – Wendepunkt

3.3.1 Nomen

  • der Wendepunkt (m., -e)
    → 轉捩點、關鍵變化
    → 複合詞：wenden（轉向）+ Punkt
    → 例句：Das Gespräch mit den Jugendlichen war ein Wendepunkt.

  • der Kampfsport (m., -arten)
    → 格鬥運動（如拳擊、柔道）
    → 複合詞：Kampf + Sport
    → 例句：Fahim betreibt seit Jahren Kampfsport.

  • die Struktur (f., -en)
    → 結構、規律
    → 例句：Sport gibt den Jugendlichen Struktur und Halt.

  • der Halt (m., kein Pl.)
    → 支撐、依靠（心理層面）
    → 例句：Viele junge Menschen suchen Halt im Alltag.

3.3.2 Verben

  • sich erinnern an + Akk. (Verb: erinnern)
    → 回憶起
    → 例句：Er erinnert sich noch gut an das Gespräch.

  • sich engagieren für + Akk. (Verb: engagieren)
    → 投入、積極參與
    → 例句：Er engagiert sich für Jugendliche im Stadtteil.

  • sich unterhalten mit + Dativ / über + Akk. (Verb: unterhalten)
    → 聊天、交談
    → 例句：Er unterhielt sich mit ihnen über ihr Leben.

  • jemanden überzeugen von + Dativ (Verb: überzeugen)
    → 說服某人
    → 例句：Er konnte die Jugendlichen vom Boxen überzeugen.

  • etwas schaffen (+ Akk.)
    → 成就、辦到（此處為口語：成功做到）
    → 例句：Fahim schaffte es, das Vertrauen der Jugendlichen zu gewinnen.

3.3.3 Adjektive

  • beeindruckt (von …) (Partizip II von beeindrucken)
    → 受到印象深刻的
    → 例句：Die Jugendlichen waren beeindruckt von seiner Geschichte.

  • interessiert an + Dativ
    → 對⋯⋯感興趣
    → 例句：Sie waren sofort am Boxtraining interessiert.

3.4 Abschnitt 4 – Sportverein & Training

3.4.1 Nomen

  • der Verein (m., -e)
    → 社團、協會（體育會）
    → 例句：Fahim gründete seinen eigenen Verein.

  • das Vorbild (n., -er)
    → 榜樣、模範
    → 複合詞：vor-（在前）+ Bild
    → 例句：Er wurde für viele Jugendliche ein Vorbild.

  • das Training (n., -s)
    → 訓練
    → 例句：Im Training lernen die Jugendlichen Disziplin.

  • die Disziplin (f., -en)
    → 紀律、自律；詞源為拉丁文 disciplina
    → 例句：Kampfsport vermittelt Disziplin und Respekt.

  • der Respekt (m., kein Pl.)
    → 尊重
    → 例句：Die Jugendlichen lernen Respekt im Umgang miteinander.

  • die Selbstbeherrschung (f., kein Pl.)
    → 自我控制
    → 複合詞：Selbst + Beherrschung（控制）
    → 例句：Boxtraining fördert die Selbstbeherrschung.

3.4.2 Verben

  • gründen (+ Akk.)
    → 創立、成立
    → 例句：Er gründete einen eigenen Sportverein.

  • vermitteln (+ Akk. / Dativ + Akk.)
    → 傳授、傳遞（價值、技能）
    → 例句：Der Sport vermittelt Werte wie Disziplin.

  • betreiben (+ Akk.)
    → 從事（某項活動）
    → 例句：Er betreibt seit Jahren Kampfsport.

  • sich benehmen (Verb, reflexiv)
    → 表現、舉止（常與規矩相關）
    → 例句：Sie lernen im Training, sich gut zu benehmen.

3.4.3 Redemittel / feste Wendungen

  • Verantwortung übernehmen
    → 承擔責任
    → 例句：Im Verein lernen die Jugendlichen, Verantwortung zu übernehmen.

  • Disziplin und Respekt zeigen
    → 展現紀律與尊重
    → 例句：Der Kampfsport verlangt Disziplin und Respekt.

  • ein Vorbild sein (für + Akk.)
    → 成為榜樣
    → 例句：Fahim ist ein Vorbild für viele junge Menschen.

3.5 Abschnitt 5

3.5.1 Nomen

  • die Stresssituation (f., -en)
    → 壓力情境
    → 複合詞詞源：Stress + Situation
    → 例句：Die Jugendlichen lernen, Stresssituationen ohne Waffe zu bewältigen.

  • die Regel (f., -n)
    → 規則、規矩
    → 例句：Sie lernen, sich an Regeln zu halten.

  • die Beleidigung (f., -en)
    → 侮辱、辱罵
    → 來自動詞 beleidigen
    → 例句：Wer jemanden beleidigt, muss Liegestütze machen.

  • die Liegestütze (f., -n)
    → 伏地挺身
    → 常與動詞 machen 搭配
    → 例句：Bei schlechtem Benehmen müssen sie Liegestütze machen.

  • die Zukunftspläne (f., Pl.)
    → 未來計劃
    → 複合詞詞源：Zukunft + Plan
    → 例句：Die Jugendlichen entwickeln eigene Zukunftspläne.

  • die Hausaufgabe (f., -n)
    → 作業
    → 例句：Einige machen direkt nach dem Training ihre Hausaufgaben.

  • die Sachbeschädigung (f., -en)
    → 財物損壞、器物毀損
    → 複合詞詞源：Sache + Beschädigung（損壞）
    → 例句：Die Zahl der Sachbeschädigungen ist stark zurückgegangen.

3.5.2 Verben

  • bewältigen (+ Akk.)
    → 克服、處理（壓力或困難情境）
    → 例句：Sie lernen, Konflikte ohne Gewalt zu bewältigen.

  • sich an etwas halten (+ Akk.)
    → 遵守、堅持（如規則）
    → 例句：Die Jugendlichen lernen, sich an Regeln zu halten.

  • fluchen (intransitiv)
    → 咒罵、罵髒話
    → 例句：Wer im Training flucht, muss Liegestütze machen.

  • beleidigen (+ Akk.)
    → 侮辱某人
