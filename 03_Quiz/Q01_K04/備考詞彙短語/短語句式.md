## 一、句型結構（包含從句、虛擬語氣、比較結構）

- Es gibt ... → 有……（存在句）
- Es lässt sich ... → 可以被……（被動+不定式）
- gilt als ... → 被視為……
- Wenn ..., dann ... → 如果……那麼……
- Obwohl ..., trotzdem ... → 雖然……儘管如此……
- Je ... desto ... → 越……越……
- Nicht nur ..., sondern auch ... → 不僅……而且……
- Sowohl ... als auch ... → 無論……也……
- Damit ... → 為了……
- Um ... zu ... → 為了……
- Wer ..., der ... → 凡是……的人就……
- Es stellt sich die Frage, ob ... → 問題在於是否……
- Es fällt auf, dass ... → 引人注意的是……
- Es ist offensichtlich, dass ... → 很明顯……
- Meiner Meinung nach ... → 依我之見……
- Ich bin der Meinung, dass ... → 我認為……

## 八、典型 B2 複合句原句摘錄（KB 文章真實出處）

- „Manche Jugendliche wissen nicht, was sie tun sollen, **weil sie sich ausgeschlossen fühlen.**“  
  → 一些青少年不知道該做什麼，因為他們感覺被排斥。

- „**Je mehr sie trainieren, desto selbstbewusster werden sie.**“  
  → 他們訓練得越多，就越有自信。

- „**Damit sie besser mit Konflikten umgehen können**, lernen sie Regeln.“  
  → 為了更好地應對衝突，他們學習規則。

- „**Es ist offensichtlich, dass** soziale Ungleichheit langfristige Folgen hat.“  
  → 很明顯，社會不平等會帶來長期後果。
