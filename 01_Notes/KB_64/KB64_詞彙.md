# KB 64 重點生詞清單：*Was Frauen und Männer wirklich wollen*

## 1. Soziale Strukturen & Gesellschaft

- **die Erwerbsarbeit**  
  → 有報酬的工作；正式語體  
  → 搭配：*Erwerbsarbeit leisten / unterbrechen*

- **die Vereinbarkeit (von … und …)**  
  → 可協調性、可兼顧性  
  → 常見搭配：*Vereinbarkeit von Beruf und Familie*

- **die Familiengründung**  
  → 組建家庭（結婚＋生子）  
  → 搭配：*Familiengründung hinauszögern*

- **die unbezahlte Arbeit**  
  → 無酬勞動，如家務、照顧小孩  
  → 搭配：*unbezahlte Arbeit leisten / übernehmen*

- **kinderfeindlich (Adj.)**  
  → 對育兒不友善的，反育兒的社會風氣  
  → 搭配：*eine kinderfeindliche Gesellschaft*

- **die Kindererziehung**  
  → 教養、育兒  
  → 搭配：*sich um die Kindererziehung kümmern*

- **die Pflege**  
  → 照顧（老人、病人）  
  → 搭配：*Pflege übernehmen / leisten*

---

## 2. 心理狀態 & 判斷

- **selbstbewusst (Adj.)**  
  → 有自信的  
  → 搭配：*selbstbewusst auftreten / sein*

- **zuversichtlich (Adj.)**  
  → 有信心的、對未來樂觀的  
  → 搭配：*zuversichtlich in die Zukunft blicken*

- **etwas (Akk.) bewerten**  
  → 評估、評價某事  
  → 搭配：*etwas positiv / schlecht bewerten*

- **unentschlossen (Adj.)**  
  → 猶豫不決的  
  → 搭配：*unentschlossen bleiben*

---

## 3. 慣用語與語篇連接

- **auf der Strecke bleiben** *(Redewendung)*  
  → 被拋下、失敗、落後  
  → 用法：*Ohne Ausbildung bleibt man auf der Strecke.*

- **hinzu kommt**  
  → 此外、還有一點是⋯⋯（新聞用語）  
  → 常見開頭句式：*Hinzu kommt: …*

- **obgleich / obwohl**  
  → 儘管（引導讓步句）  
  → 結構：*Obgleich X, passiert Y.*

- **ebenso … wie …**  
  → 和⋯⋯一樣⋯⋯（比較結構）  
  → 用法：*ebenso selbstbewusst wie …*

---

## 4. 動詞搭配與表達意願

- **sich (Dat.) etwas wünschen**  
  → 希望得到⋯⋯  
  → 搭配：*sich eine Balance wünschen*

- **etwas hinauszögern**  
  → 延遲、拖延某事  
  → 搭配：*die Entscheidung / Familiengründung hinauszögern*

- **etwas übernehmen**  
  → 承擔、接手（責任、工作）  
  → 搭配：*Hausarbeit / Pflege übernehmen*

- **auf etwas (Akk.) eingehen**  
  → 顧及、回應（如公司對員工的需求）  
  → 搭配：*auf Wünsche von Eltern eingehen*


## 5. 動詞 & 表態相關動詞

- **etwas beurteilen**  
  → 評價、判斷  
  → 替換用語：*bewerten, einschätzen*  
  → 搭配：*die Situation / die Vereinbarkeit beurteilen*

- **etwas feststellen**  
  → 發現、察覺（書面語常用）  
  → 搭配：*Unterschiede feststellen, Ergebnisse feststellen*

- **zustimmen (Dat.)**  
  → 同意某事（注意第三格！）  
  → 搭配：*der Aussage zustimmen*

- **zögern (mit …)**  
  → 猶豫、遲疑  
  → 搭配：*mit der Entscheidung / Familiengründung zögern*

- **erleben + Akk. als + Adj.**  
  → 感受到⋯⋯是怎樣的  
  → 搭配：*die Gesellschaft als ungerecht erleben*

- **bleiben + Adjektiv / Nomen**  
  → 保持⋯⋯狀態  
  → 搭配：*im Nachteil bleiben / unentschlossen bleiben*

---

## 6. 社會學／調查研究常見詞

- **die Befragten**  
  → 受訪者（來自動詞 befragen 的名詞化）  
  → 搭配：*Die befragten Frauen / Männer*

- **die Studie**  
  → 研究、調查  
  → 搭配：*Ergebnisse einer Studie, laut Studie*

- **der Wertewandel**  
  → 價值觀的變化（抽象名詞）  
  → 用法：*Ein Wertewandel ist erkennbar.*

- **die Einstellung (zu …)**  
  → 對⋯⋯的態度  
  → 搭配：*Einstellungen zu Arbeit, Familie, Karriere*

- **der Wunsch nach …**  
  → 對⋯⋯的渴望  
  → 搭配：*Wunsch nach Nachwuchs / Gleichberechtigung*

---

## 7. 書面語常見形容詞 &副詞

- **mehrheitlich**  
  → 大多數情況下、主要地  
  → 替換：*größtenteils, überwiegend*

- **beruflich (Adj./Adv.)**  
  → 在職業上的  
  → 搭配：*beruflich im Nachteil sein*

- **gesellschaftlich**  
  → 社會上的、從社會角度來看  
  → 用法：*gesellschaftliche Rollenverteilung*

- **rückhaltend / zurückhaltend**  
  → 保留的、謹慎的（態度）  
  → 搭配：*etwas zurückhaltend beurteilen*

- **zufrieden / unzufrieden mit …**  
  → 滿意／不滿意（Dativ）  
  → 搭配：*zufrieden mit dem Leben*

---

## 8. 常見搭配句型（建議熟記）

- **„Wer Kinder hat, kann keine wirkliche Karriere machen.“**  
  → 表觀點的引用句式，可作為作文論點引入

- **X bleibt Frauensache.**  
  → 表社會角色分工的定性句型

- **Immer mehr Menschen meinen, dass …**  
  → 書面語中非常常見的意見引入方式

- **Obgleich / Obwohl ... , bleibt ...**  
  → 表轉折讓步句型，邏輯結構句（B2作文關鍵句式）

- **Heute sehen viele ihre Chancen als schlecht.**  
  → 表主觀評價 + 時間對比（建議練習改寫為：*Heute bewerten sie …*）
